# MeshQuokka logo

Original quokka and radio-network mark created for S. van Ingen.

- MeshQuokka-Logo.svg: scalable export.
- MeshQuokka-Logo.png: transparent 384 x 384 export.
- meshquokka-logo.json: drawing primitives in a 96 x 96 coordinate space.
- ../vendor/meshdeck/firmware/ui/MeshQuokkaLogo.h: native Adafruit GFX drawing used on the device (RGB565 colours).

The firmware does not load a bitmap at startup or depend on external storage.
